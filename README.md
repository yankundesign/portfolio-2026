# Portfolio 2026

Yankun's portfolio site — a desk scene homepage, spatial canvas for works, and vertical-scroll case studies. Built with the Field Notebook's visual language (ink-on-paper, Fraunces typography, editorial plates).

## Structure

- `00-brief/` — Design briefs and the vibe guideline (source of truth)
- `01-content/` — Case study writing drafts (markdown)
- `03-prototype-explore/` — Early HTML prototype explorations
- `04-reference/` — Visual references
- `site/` — The Vite + React SPA (deployable)

## Development

```bash
cd site
npm install
npm run dev
```

## Deploy

Vercel or Cloudflare Pages. Root directory: `site/`. Output: `dist/`.
