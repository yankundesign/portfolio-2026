Support

Ebb adds three breaths between opening a supported feed and entering it. It works through a Personal Automation that you create and control in Apple Shortcuts.

Last updated · August 23, 2026

Set up an app

  1. Open Ebb and choose TikTok or Instagram.
  2. Tap Open Shortcuts.
  3. Create a Personal Automation: App → choose the same app → Is Opened → Run Immediately.
  4. Turn Notify When Run off.
  5. Add the action Check Ebb Intercept and set Target to the same app.
  6. Return to Ebb, tap I've set it up, then open the selected app to verify it.

If Ebb does not appear

  • Confirm that the automation is enabled and set to Run Immediately.
  • Confirm that Check Ebb Intercept targets the same app as the automation trigger.
  • Confirm that Ebb and the selected app are both installed.
  • Open Ebb once, then try the selected app again.
  • If you recently tapped Continue, open the app again after 15 seconds. Ebb briefly suppresses a repeat trigger so it does not bounce you back into the pause.

Remove an app

In Ebb, open Settings and choose Remove TikTok or Remove Instagram. Then delete the matching automation in Shortcuts. Removing it only inside Ebb does not delete the Shortcuts automation.

Export history

Open Ebb → Settings → Export events. You choose where the exported file is saved or sent. Ebb does not receive the export.

Delete data

Deleting Ebb removes the data stored by Ebb on your iPhone. Any copy you previously exported remains wherever you saved it.
