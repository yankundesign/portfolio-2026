# Alive Data Specimen

Standalone prototype for an animated data-organism card.

The first version keeps the idea small:

- preset silhouettes made from animated sparkle marks
- density and current controls
- pointer disturbance on the specimen
- rough high-contrast image mask import

Open `index.html` directly in a browser. No install or build step is required.

## Direction

The interaction tests whether technical material can become organic when the system disappears into the motion. Fish swim, jellyfish pulse, and butterflies flutter. The current upload path only works well with clean, high-contrast silhouettes or transparent PNGs. A production version should replace that with real subject segmentation before it moves into the portfolio.
